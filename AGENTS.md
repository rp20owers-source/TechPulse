# Shared agent instructions

Read PROJECT_HANDOFF.md, docs/architecture/ARCHITECTURE.md and TASKS.md before changes. Preserve user files. Work on an assigned branch/worktree and avoid overlapping module ownership. Never change another agent's dependencies without coordination.

No fabricated market data, attribution, tests, confidence or release claims. Demo data must use fictional assets and conspicuous labels. Never execute trades. No secrets, restricted datasets, caches, imported personal records or generated user reports in Git. Only authorized official provider endpoints; no scraping around restrictions.

Financial calculations need focused tests. Scores are research heuristics, never probabilities. Insufficient evidence means abstain. Use publication dates for disclosures and actual obligations for contract analysis. Options premium is size × price × multiplier only for an observed individual trade, not volume × last price.

After every pass archive the prior PROJECT_HANDOFF.md to docs/handoffs/ and update it with role, task, files, decisions, commands, actual checks, issues, failed approaches, dependencies, branch/checkpoint, next task and acceptance criteria. Maintain honest requirement coverage and phase gates. A native desktop app is the target; do not replace with a web site.
