# Roadmap and acceptance gates

No phase is complete merely because a navigation page exists. Initial delivery targets a usable research preview, with supported imports and explicit unavailable coverage where free lawful data is insufficient.

| Phase | Acceptance gate | Initial state |
|---|---|---|
| 00 Research | Ten competitors, academic evidence, all named providers and licensing constraints documented with official sources | In progress |
| 01 Repository | Shared agent docs, MIT/license review, CI, GitHub source publication verified | In progress |
| 02 Foundation | Native shell, SQLite isolation, provenance, offline fixtures, recovery and tests | Planned |
| 03 Equities | Validated OHLC import, daily/5/21-session movers, volume and filters, watchlists | Planned |
| 04 Crypto | Independent dashboard, authorized local import/optional Demo provider; category separation | Planned |
| 05 Technical | Tested indicators and objective patterns; chronological evaluation; no unsupported forecasts | Planned |
| 06 Options | Validated authorized trade/aggregate imports, accurate premiums, coverage caveats | Planned |
| 07 Politics | Separate workspaces, owner/date/range provenance; statutory gate; no bundled actual records | Planned |
| 08 Contracts | Award-level imports/search, ceilings vs obligations, verified company mapping | Planned |
| 09 Opportunities | Explainable weights, contradictory evidence, abstention; local paper ledger and benchmark | Planned |
| 10 Reporting | Four formats, sections, archive; opt-in Monday catch-up in app | Planned |
| 11 GUI | Dark/light, sort/search/filter, interactive charts, usable empty/error states, visual review | Planned |
| 12 Validation | Independent reviews, financial/security tests, regression pass, limitations inventory | Planned |
| 13 Distribution | Reproducible lock, Windows build, smoke test, verified release; clean machine gate | Planned |
| 14 Final audit | Honest coverage matrix, unresolved risks, updated handoff and follow-up backlog | Planned |
